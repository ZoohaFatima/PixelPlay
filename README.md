# 🎮 PixelPlay

**PixelPlay** is a compact handheld gaming console built around the ESP32 and an 8×8 LED matrix display. The goal of the project is to create a portable retro-style gaming device capable of running simple arcade games while maintaining a small form factor and low power consumption.

> 🚧 **Current Status: Prototype Development**

## 📖 Overview

PixelPlay is designed as an affordable and educational gaming platform that demonstrates embedded systems, game development, and hardware interfacing. The current prototype focuses on establishing the core hardware and software architecture before moving to a custom enclosure and advanced features.

## ✨ Current Features

* ESP32-based game controller
* 8×8 LED matrix display output
* Button-based user input
* Real-time game rendering
* Portable design concept
* Expandable game framework

## 🔧 Hardware Used

| Component                  | Purpose              |
| -------------------------- | -------------------- |
| ESP32                      | Main microcontroller |
| 8×8 LED Matrix (MAX7219)   | Game display         |
| Push Buttons               | User controls        |
| Breadboard / Prototype PCB | Circuit prototyping  |
| USB Power Source           | Power supply         |
